# football-tracking-analytics-engine
# ⚽ Football Tracking Analytics Engine

A Python-based football tracking analytics engine built using SkillCorner's open tracking dataset.

The project transforms raw player and ball tracking coordinates into live tactical and physical performance insights through interactive visualizations and advanced analytics.

---

## Features

### Live Tracking

- Player tracking animation
- Ball tracking
- Shirt numbers
- Team colours
- Player movement trails

### Physical Analytics

- Fastest player
- Distance covered
- Sprint detection
- Sprint leader

### Tactical Analytics

- Player possession
- Heat maps
- Convex Hull
- Team Width
- Team Length

---

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
- mplsoccer

---

## Dataset

SkillCorner Open Tracking Data

- Match metadata (JSON)
- Tracking frames (JSONL)
